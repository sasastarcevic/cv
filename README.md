# Saša Starčević — CV

Personal CV website for [Saša Starčević](https://www.linkedin.com/in/sasa-starcevic/).

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy on GitHub Pages

1. Push this repo to GitHub (`sasastarcevic/cv`).
2. In the repo: **Settings → Pages**.
3. Source: **Deploy from a branch** → `main` → `/ (root)`.
4. Site URL will be `https://sasastarcevic.github.io/cv/`.
